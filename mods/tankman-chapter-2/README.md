# Friday Night Funkin' — Vs. Tankman: Chapter 2

**Original fan-made mod for P-Slice.** All Chapter 2 music, charts, imagery and animation frames are generated from original procedural code; no Week 7 recordings or sprite sheets are repackaged.

## The six tracks
1. **Redeploy** (140 BPM)
2. **Blackout** (155 BPM)
3. **Onslaught** (165 BPM)
4. **Warzone** (170 BPM)
5. **Last Stand** (180 BPM)
6. **No More Heroes** (190 BPM)

## What is included
- One Story Mode week with six linked songs, and Freeplay entries
- Three charts per song (Easy, Normal, Hard)
- A new Sparrow-style animated character sheet, character JSON, custom health icon
- Procedurally composed demos exported to Ogg Vorbis
- Original background layers, red signal effects, and Lua HUD branding
- A branch-only Haxe menu with six-song selection; dedicated entry in desktop/mobile main menus

**Important:** This is a **playable prototype** with synthesized instrumental demos, not a professionally mixed soundtrack or hand-animated production. Visuals/audio are generated by `tools/chapter2_factory.py` then committed by GitHub Actions.

## Installation
In the branch, keep the `mods/tankman-chapter-2` folder in the engine `mods` directory. In the Mods menu enable the pack and restart if necessary. To play from the regular menus, select the Chapter 2 week in Story Mode or its songs in Freeplay. A Chapter 2 entrance also exists on the main menu for this branch.

For Android, the `mods` folder must be installed in the location supported by your P-Slice mobile build. Some builds bundle mods and others require copying the mod separately.

## How to regenerate
Run `python -m pip install pillow numpy` then `python tools/chapter2_factory.py` with `ffmpeg` installed. The workflow `.github/workflows/chapter2-assets.yml` automates this and commits output.
